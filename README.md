Arcane: Spell Catcher


Game Description

Arcane: Spell Catcher is a 2D reimagining of the Apple Picker prototype.
Instead of catching apples, the player controls a magical sigil that catches falling orbs.
The game is endless and continues until the player loses all lives.
Different types of orbs fall from an ancient runic source above the screen. The player must catch the correct orbs while avoiding dangerous ones.

How to Play:
Move the mouse left and right to control the sigil.
Catch blue orbs to score and stay alive.
Avoid dangerous or unstable orbs.
Missing too many blue orbs results in losing lives.
The game ends when all lives are lost.
After losing, you can play again or return to the main menu.

Difficulty Modes:
Easy
-Slower pace
-Fewer hazards
-Designed for learning movement and timing
Medium
-Wind affects falling orbs
-Requires more precise positioning
Hard
-Multiple orb types
-Faster falling speed
-Greater challenge and reaction timing required
Eldritch (Extra Mode)
-Combines wind, faster spawning, and all orb types
-Most chaotic and difficult mode

Features:
Fully sprite-based 2D visuals
Animated orb effects
Sound effects when orbs are caught
Main menu with difficulty selection
Game over screen with replay options
